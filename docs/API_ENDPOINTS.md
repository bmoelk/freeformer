# FreeFormer API Endpoints Reference 📡

This document provides complete, detailed specifications for all REST API endpoints exposed by the FreeFormer Worker.

---

## 📑 Summary sitemap

| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| `GET` | [`/`](#get-) | Service health check & metadata | None |
| `GET` | [`/form-handler.js`](#get-form-handlerjs) | FreeFormer Client JavaScript library script | None |

| `GET` | [`/submissions/:formId`](#get-submissionsformid) | List paginated submissions for a specific form | `Bearer API_KEY` |
| `GET` | [`/submission/:id`](#get-submissionid) | Retrieve details for a single submission by ID | `Bearer API_KEY` |

## 1. Public Endpoints

### `GET /`

Returns service health, version info, active bindings, and spam engine diagnostic status.

#### Request
```http
GET / HTTP/1.1
Host: your-worker.workers.dev
```

#### Response (`200 OK`)
```json
{
  "service": "FreeFormer",
  "version": "0.3.0",
  "status": "healthy",
  "timestamp": "2026-09-13T12:00:00.000Z"
}
```

---

### `GET /form-handler.js`

Serves the built-in FreeFormer client JavaScript library file with proper `Content-Type: application/javascript`, CORS headers, and edge caching (`Cache-Control: public, max-age=3600`).

#### Request
```html
<script src="https://your-worker.workers.dev/form-handler.js"></script>
```

---

### `POST /submit`

Ingests form data from client forms, verifies anti-spam Turnstile tokens, persists submissions to KV / D1 storage, and triggers outbound email alerts or webhooks.

#### Headers
```http
Content-Type: application/json
```

#### Request Payload
```json
{
  "formId": "contact",
  "siteId": "mysite",
  "turnstileToken": "0.1x000000000000000000...",
  "data": {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "message": "Hello from FreeFormer!"
  }
}
```

#### Field Specifications
* `formId` *(string, required)*: Identifier for the form (e.g., `contact`, `newsletter`).
* `siteId` *(string, required)*: Explicit website identifier (e.g., `splitphase`, `brainendeavor`). Used to partition storage keys and route to site-specific secrets and email alert recipients.
* `turnstileToken` *(string, required)*: Token generated by the Cloudflare Turnstile widget.
* `data` *(object, required)*: Key-value dictionary containing form field inputs.

> [!NOTE]
> **Spam Scoring & Quarantine Behavior**:
> Submissions are evaluated across honeypots, timing velocity, link density, and burner email domains. If `spamScore >= SPAM_THRESHOLD` (default: `60`), the submission is safely quarantined in D1/KV storage (`metadata.isSpam = true`) and instant email alerts are suppressed. The endpoint returns `200 OK` with a valid `submissionId` so automated bots cannot infer anti-spam rules.

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "submissionId": "f8a92b10-c3d4-4e5f-9a1b-2c3d4e5f6a7b",
  "message": "Form submitted successfully"
}
```

#### Error Responses

##### `400 Bad Request` (Missing fields)
```json
{
  "success": false,
  "error": "Site ID is required. Please provide 'siteId' in the payload or specify 'data-freeformer-site' on your form."
}
```

##### `403 Forbidden` (Turnstile failure)
```json
{
  "success": false,
  "error": "Turnstile verification failed",
  "details": ["invalid-input-response"]
}
```

##### `429 Too Many Requests` (Rate limit exceeded)
```json
{
  "success": false,
  "error": "Rate limit exceeded",
  "retryAfter": 45
}
```

## 2. Authenticated Admin Endpoints

All admin endpoints require an `Authorization` HTTP header with a Bearer token matching your `API_KEY` worker secret:

```http
Authorization: Bearer YOUR_API_KEY
```

---

### `GET /submissions/:formId`

Lists historical form submissions stored for a specific `formId` and `siteId`. Requires the `?siteId=` query parameter, with optional pagination (`limit`, `offset`) and status filtering (`filter=all|clean|spam`).

#### Request
```http
GET /submissions/contact_form?siteId=brainendeavor&limit=50&offset=0&filter=clean HTTP/1.1
Host: your-worker.workers.dev
Authorization: Bearer YOUR_API_KEY
```

#### Response (`200 OK`)
```json
{
  "success": true,
  "formId": "contact_form",
  "siteId": "brainendeavor",
  "submissions": [
    {
      "id": "f8a92b10-c3d4-4e5f-9a1b-2c3d4e5f6a7b",
      "formId": "contact_form",
      "siteId": "brainendeavor",
      "data": {
        "name": "Jane Doe",
        "email": "jane@example.com",
        "message": "Hello from FreeFormer!"
      },
      "metadata": {
        "ip": "203.0.113.195",
        "userAgent": "Mozilla/5.0...",
        "timestamp": "2026-08-18T14:23:52.000Z",
        "turnstileScore": 1.0
      }
    }
  ],
  "pagination": {
    "limit": 50,
    "offset": 0
  }
}
```

```http
Host: your-worker.workers.dev
Authorization: Bearer YOUR_API_KEY
```

### `GET /admin` & `GET /admin/submissions/:id` (Zero-Trust Admin Dashboard)

Lightweight, server-rendered dashboard powered by `hono/html`. Protected by **Cloudflare Zero Trust** (`Cf-Access-Jwt-Assertion` header or `CF_Authorization` cookie) or Bearer `API_KEY`.

- **`/admin`**: Lists submissions with multi-tenant site and form filters, pagination, Turnstile scores, and attachment indicators.
- **`/admin/submissions/:id`**: Detailed submission inspector displaying full submitted payload (highlighting protected fields omitted from email), metadata, and direct R2 file preview/download links.

---

### `GET /files/:key*` (Secure Zero-Trust File Access)

Streams stored attachments directly from private Cloudflare R2 bucket (`ATTACHMENTS`).
Requires valid Cloudflare Zero Trust authentication or Bearer `API_KEY`.
Always serves files with sandboxed security headers (`Content-Disposition: attachment`, `Content-Security-Policy: default-src 'none'; sandbox`, `X-Content-Type-Options: nosniff`).

---

### `GET /files/signed` (Automated Webhook File Access)

Time-limited HMAC-signed file download endpoint for automated webhook consumers (e.g. Zapier, Make, n8n) that cannot log in interactively through Cloudflare Access.

#### Query Parameters
- `key`: The namespaced R2 file storage key
- `expires`: UNIX timestamp of URL expiration
- `token`: HMAC-SHA256 signature generated with `WEBHOOK_SECRET`

---

### `POST /webhook-test`

Dispatches a simulated submission payload to test webhook receivers (Zapier Catch Hooks, Make, n8n, custom APIs).
Requires valid Cloudflare Zero Trust session or Bearer `API_KEY`.

#### Request
```http
POST /webhook-test HTTP/1.1
Host: your-worker.workers.dev
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "siteId": "splitphase.io",
  "formId": "contact",
  "webhookUrl": "https://hooks.zapier.com/hooks/catch/..."
}
```

### `POST /admin/spam-digest`

On-demand trigger or dry-run preview for the periodic spam digest. 
Requires valid Cloudflare Zero Trust session or Bearer `API_KEY`.

#### Query Parameters
- `days` *(number, optional, default: `7`)*: Aggregation window in days.
- `siteId` *(string, optional)*: Filter digest to a single site identifier.
- `dryRun` *(boolean, optional, default: `false`)*: If `true`, compiles and returns the digest summary payload without dispatching an email.

#### Request
```http
POST /admin/spam-digest?days=7&dryRun=true HTTP/1.1
Host: your-worker.workers.dev
Authorization: Bearer YOUR_API_KEY
```

#### Response (`200 OK`)
```json
{
  "sent": true,
  "count": 3,
  "digestData": {
    "periodStart": "Sep 6",
    "periodEnd": "Sep 13, 2026",
    "totalSubmissions": 25,
    "spamSubmissions": 3,

    "spamPercentage": "12.0%",
    "items": [
      {
        "id": "sub_123",
        "siteId": "splitphase.io",
        "formId": "contact",
        "timestamp": "Sep 11, 09:30 AM",
        "senderEmail": "bot@mailinator.com",
```
